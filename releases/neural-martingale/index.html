Neural martingale dual bounds

Pricing a Bermudan put from both sides: a lower bound from regression, an upper bound from a neural network, and a gap that says how much to trust either.

github.com/hajar6883/Neural_martingale_learning

The constraint

A Bermudan option can be exercised on any of a fixed set of dates. There is no closed form, so the standard answer is Longstaff–Schwartz: regress continuation values on the simulated paths and exercise when the payoff beats them. Any exercise rule you can write down is at best optimal, so the price it gives is a lower bound. On its own it doesn't say how far below the true price it sits.

Rogers' duality closes the other side. For any martingale M starting at zero, E[maxt(discounted payofft − Mt)] is an upper bound, and the bound is tight when M is the Doob martingale of the value process. The quality of the upper bound is entirely the quality of the martingale.

How it works

  GBM paths            8,000 paths, 10 exercise dates
        |
        +--> LSMC          polynomial regression, backward induction  -> lower bound
        |
        +--> martingale    ΔMt = hθ(St) · Zt
        |                 Zt = Brownian increment recovered from the path
        |
        +--> dual          minimise E[maxt(e-rtht - Mt)] over θ  -> upper bound
        |
        v
   compared against a binomial tree price

The design choice is in the parametrisation. Under GBM the Brownian increment Zt can be read back off the path, and it has zero conditional mean. Multiply it by anything that depends only on the present, here a small network hθ(St), and the result is a martingale difference by construction. Every set of weights gives a valid upper bound, so training is plain minimisation of the dual objective: no penalty term pushing the network towards martingality, and no bound that is only valid if training went well.

Two classical upper bounds sit alongside it as baselines: the Doob martingale built from the LSMC continuation values, and the same martingale scaled by the best scalar.
